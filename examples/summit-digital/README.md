# Summit Digital — Populated Example

**Everything in this folder is fictional.** It shows what a brain looks like after ~6 months
of real use, so you know what you're writing toward. Names, businesses, dates, dollar
amounts, and events are all invented — copy the *shape*, not the content.

Summit Digital is a solo-founder marketing agency run by Alex Rivera in Boise, Idaho, with
one retainer client (Canyon Roofing Co.) and one project client in flight (Lakeside Dental).
Notice the texture: an overdue invoice, a task blocked on a client, a superseded decision, a
quarter that got rescoped. A real brain is full of that — a spotless one is a stale one.
